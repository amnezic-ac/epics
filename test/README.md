The test suite is fully implemented with [Pytest](https://docs.pytest.org/en/stable/index.html)

Pytest is customized on this project, so if Pytest does not behave as usually expected, please refer to `pytest.toml` file in the root level. Please find the full [configuration reference](https://docs.pytest.org/en/stable/reference/reference.html#ini-options-ref).

For full Pytest API reference, please refer to the [official reference](https://docs.pytest.org/en/stable/reference/reference.html#ini-options-ref).
